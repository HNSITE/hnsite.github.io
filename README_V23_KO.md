# CHURANG v23 - 알파벳 빙고 추가

## 적용 순서

1. Firebase Console > Firestore Database > 규칙에서 `firestore.rules` 전체 내용을 교체하고 게시합니다.
2. GitHub Pages 저장소에 아래 파일을 같은 경로로 교체합니다.
   - `app.html`
   - `bingo.html`
   - `bingo-room.html`
   - `kill.html`
   - `assets/styles.css`
   - `js/bingo.js`
   - `js/bingo-room.js`
   - `js/update-modal.js`
3. GitHub Pages 배포가 끝난 뒤 새로고침합니다.

## 추가 기능

- 빙고방 생성 시 `숫자 빙고` / `알파벳 빙고` 선택
- 알파벳 빙고 배치 방식
  - 무작위 배치
  - 직접 지정
- 무작위 배치
  - 26칸 이하: A~Z 중 필요한 수만큼 중복 없이 섞어서 배치
  - 27칸 이상: A~Z를 반복하여 필요한 칸 수를 채운 뒤 전체를 섞어서 배치
- 직접 지정
  - 각 칸 A~Z 한 글자
  - 중복 허용
  - 소문자는 자동으로 대문자 변환
  - 빈칸이 있으면 방 생성 불가
- 기존 숫자 빙고방은 `숫자 빙고`로 그대로 동작
- 사진을 넣은 알파벳 빙고도 기존 사진 빙고 동작을 그대로 사용
- 업데이트 소식에 알파벳 빙고 추가 내용 표시

## 변경하지 않은 기능

- 빙고 체크/전체 선택/전체 해제
- 완성 빙고/남은 칸/치킨 수량
- 사진 업로드 및 표시
- 참가자 관리
- 사용자 관리
- 방 나가기/방 삭제
- 업데이트 모달 동작

## 확인 항목

- 기존 숫자 빙고방 진입 및 체크
- 알파벳 무작위 3x3 / 5x5 생성
- 알파벳 직접 지정에서 중복 입력
- 소문자 입력 시 대문자 변환
- 직접 지정 빈칸 상태에서 생성 차단
- 알파벳 방 새로고침 후 같은 글자 배열 유지
- 참가자 계정에서도 같은 알파벳 배열 표시
- 사진을 넣었을 때 체크 칸에 이미지 조각 표시
