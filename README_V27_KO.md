# CHURANG v27 통합 개선본

기준본: v25 + v26 개선 작업

## 역할 구조

- `developer` : 개발자. 화면에 **개발자**로 표시됩니다. 기능 테스트와 문제 확인을 위해 최고관리자 수준의 운영/빙고 기능을 사용할 수 있습니다. **업데이트 소식 등록·수정·삭제는 개발자만 가능합니다.**
- `super_admin` : 최고관리자. 실제 서비스 운영의 최종 관리자/소유자입니다. 사용자 승인, 권한, 관리자 운영을 담당합니다.
- `admin` : 관리자. 일반 사용자 승인/상태/기능 권한을 관리합니다.
- `user` : 일반 사용자.

## 최초 1회 역할 전환

현재 최고관리자로 로그인한 뒤 `사용자 관리`에서 **최고관리자 이전**을 누릅니다.
승인된 관리자가 1명일 때 그 관리자는 최고관리자로 바뀌고, 현재 최고관리자 계정은 개발자로 바뀝니다.
개발자 계정이 이미 존재하면 이 전환 버튼은 다시 사용할 수 없습니다.

## 업데이트 소식

- 업데이트 관리 버튼은 개발자에게만 표시됩니다.
- 개발자만 신규 등록, 수정, 삭제, 공개/비공개 변경을 할 수 있습니다.
- 기존 기본 업데이트 소식도 개발자가 `수정`을 누르면 Firestore에 덮어쓰기 문서가 만들어져 이후 화면에서 수정본이 사용됩니다.
- 최고관리자/관리자/일반 사용자는 공개된 업데이트만 조회할 수 있습니다.

## v26에서 함께 추가된 주요 기능

- 자유 텍스트 빙고
- 빙고방 복제
- 초대 링크 / QR 코드
- 종료 결과 요약
- 참가자 접속 상태
- 실시간 변경 알림
- 네트워크/저장 상태 안내
- 관리자 대시보드 및 CSV 내보내기
- 종료 방 검색/필터
- 즐겨찾기
- 자동 종료 옵션
- PWA 홈 화면 설치 지원
- 빙고방 감사 로그
- 체크 상태 접근성 보완

## 적용 순서

1. Firebase Firestore Database > 규칙에서 `firestore.rules` 전체 교체 후 게시
2. Firebase Storage > Rules에서 `storage.rules` 전체 교체 후 게시
3. GitHub 저장소에 `churang-bingo-v27-github`의 파일을 교체/추가
4. 기존 최고관리자로 로그인 > 사용자 관리 > 최고관리자 이전
5. 역할 변경 후 화면을 새로고침하여 `개발자` / `최고관리자` 표시 확인

실제 Firebase와 GitHub Pages 적용 화면에서 최종 동작 확인이 필요합니다.
