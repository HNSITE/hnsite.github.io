알파벳 배치 방식

알파벳 빙고의 칸을 자동으로 섞거나 직접 지정할 수 있습니다.

A~Z를 섞어 배치합니다. 27칸 이상에서는 알파벳이 반복됩니다.

알파벳 직접 지정

각 칸에 A~Z 한 글자를 입력해주세요. 같은 알파벳을 여러 번 사용해도 됩니다.

여러 글자를 복사한 뒤 첫 칸에 붙여넣어도 순서대로 입력됩니다.

자유 텍스트 직접 지정

숫자나 알파벳 대신 원하는 단어와 짧은 문구를 각 칸에 넣을 수 있습니다.

중복 입력이 가능하며 각 칸은 최대 20자입니다.

빙고 사진

사진을 선택하면 방 생성 시 자동으로 크기를 조정하고 압축하여 저장합니다.

사진을 선택하면 빙고판 생성 시 자동으로 압축 후 업로드합니다.

  • 방당 사진 1장만 저장
  • 업로드 전 자동 리사이즈·압축
  • 압축 후 최대 2MB만 허용
  • 새 사진은 같은 파일에 덮어쓰기
  • 방 삭제 시 사진도 함께 삭제
