# CHURANG v16 사용자 관리 업데이트

## 적용 기능
- 승인 대기 / 승인 완료 탭별 이름·이메일 검색
- 한 페이지 최대 10명 표시 및 이전/다음 페이징
- 이름 / 구분 / 상태 기준 정렬
- 오름차순 / 내림차순 전환
- 사용자 목록 영역 내부 세로/가로 스크롤
- 일반 사용자 삭제 기능
- 삭제 전 CHURANG 확인 모달
- 현재 빙고방 참여 정보가 남은 사용자는 삭제 차단

## 삭제 기능 범위
사용자 삭제는 Firestore의 CHURANG 서비스 사용자 프로필을 삭제합니다.
Google/Firebase Authentication 계정 자체를 삭제하는 기능은 아닙니다.
같은 Google 계정으로 다시 접속하면 신규 사용자처럼 승인 요청을 다시 할 수 있습니다.

## 적용 순서
1. Firebase Firestore Rules에 동봉된 firestore.rules 전체 내용을 게시합니다.
2. GitHub Pages에 웹 수정 파일을 같은 경로로 덮어씁니다.
3. 새 파일은 없으며 기존 파일 교체만 필요합니다.
